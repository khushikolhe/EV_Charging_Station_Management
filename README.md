# EV Charging Station Management System

## 📌 Project Overview

The **EV Charging Station Management System** is a Java-based mini project developed using **Object-Oriented Programming (OOP)** concepts.

The system is designed to manage electric vehicle charging stations, customers, vehicles, charging slots, charging sessions, billing, and payments.

---

## 🎯 Objectives

- Manage customer and vehicle information.
- Manage charging stations and charging slots.
- Allow users to book available charging slots.
- Manage charging sessions.
- Calculate charging costs and generate bills.
- Handle payment-related operations.
- Demonstrate Java OOP concepts.
- Implement multithreading where required.
- Provide a structured console-based management system.
